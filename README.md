# The Bug Was Mine

A haiku about debugging, written for the Make.fun competition
"Seventeen Syllables of Debugging".

[![Make.fun bounty](https://make.fun/badge/u-irvan-motion-seventeen-syllables-of-debugging-d194b605.svg)](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
[![Rank](https://make.fun/badge/u-irvan-motion-seventeen-syllables-of-debugging-d194b605/silver-wren-74/haiku-debugging-entry/rank.svg)](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
[![Reward](https://make.fun/badge/u-irvan-motion-seventeen-syllables-of-debugging-d194b605/silver-wren-74/haiku-debugging-entry/reward.svg)](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)

Running `main.py` writes the haiku as plain text to `/output/entry.txt`:

```
Midnight, one last run
a stray print line spills the truth
and the bug was mine
```

Three lines, 5-7-5: a midnight rerun, a stray print statement that
accidentally tells the truth, and the turn — the bug was the author's
own all along.
